Desktop, handheld, television

One build for all three. RomMix opens fullscreen and everything in it can be reached with a D-pad, so the only real difference is how far away you are sitting.

What it does

RomM holds your library. RomMix puts it on a screen you can drive from the sofa, and gets the files where your emulator will find them.

Your library, laid out for a screen

Shelves for what you were last playing, what is already on this device and your favourites — then everything on the server, searchable and filtered by platform.

Downloads into your emulator's own folder

A game lands in its emulator's own ROM folder, SD card included, so it is there when you start that emulator yourself. Multi-disc sets are unpacked and the emulator is handed the playlist, not the first disc.

Saves that follow you

Newer saves come down before you play and go back up when you quit — after showing you what is about to be sent. Every game has a tab for pulling or pushing by hand.

The emulators, installed and assigned

Four of the five install from Settings, and RomMix picks which one runs each platform. Change that per platform whenever you like.

BIOS from your own server

Per platform: what is needed, what RomM has, and what is already in place — then RomMix installs the rest. Nothing comes from anywhere but your own server.

Sign in from the couch

RomMix shows a code and a QR. Approve it in RomM on your phone — no password typed on a television keyboard.

The emulators it drives

Five, and RomMix works out which one runs each system. RetroDECK and EmuDeck each carry a dozen emulators; RetroArch runs one core per system; Eden and shadPS4 each run a single console. Settings → Platforms shows what every system will use, and lets you change it.

Getting it

You need Linux, a RomM server at version 5 or newer, and one of the emulators above — RomMix can install all of them except EmuDeck. Download the AppImage for your machine from the releases page (x86_64 for a PC or a Steam Deck, arm64 for an ARM handheld) and run it. There is nothing to install. 

chmod +x RomMix-<version>-x86_64.AppImage
./RomMix-<version>-x86_64.AppImage

From Steam, on a handheld

Download rommix-steam.sh from the same release, keep it beside the AppImage, and add the script as the non-Steam game — not the AppImage itself. 

chmod +x RomMix-<version>-x86_64.AppImage rommix-steam.sh

Steam cannot launch an AppImage directly; the script is what makes it work. The README covers building RomMix yourself, and what to do when an emulator will not start.
