RomMix

Your RomM library, on the big screen.

A Big Picture–style front end for your own RomM server. Browse it like a console dashboard, send a game to your emulator's ROM folder, play it, and let your saves go back to RomM when you quit.

Desktop, handheld, television

One build for all three. RomMix opens fullscreen and every screen in it is reachable on a D-pad, so the machine it runs on changes little more than how far away you are sitting.

What it does

RomM already holds the library. RomMix is the part that puts it on a screen you drive from the sofa, and gets the files where an emulator will find them.

Downloads where the emulator looks

A game lands in its emulator's own ROM folder, SD card included — so it is still there when you start that emulator yourself and ES-DE scrapes it as usual.

Saves that follow you

Newer saves and save states come down before you play and go back up when you quit. A per-game tab shows which side is ahead, and pulls or pushes by hand.

BIOS from your own server

Per platform: what is needed, what RomM holds and what the emulator already has — then the missing files are put in place. Nothing is fetched from anywhere else.

Multi-disc, handled

A cue+bin or a multi-disc set is unpacked into a folder of its own, and the emulator is handed the .m3u, not the .bin.

Sign in from the couch

RomMix shows a code and a QR. Approve it in RomM from your phone, and nothing secret is typed on a television keyboard.

It installs the emulators too

RetroDECK, RetroArch and shadPS4 come from Flathub, Eden from its own releases, all from Settings. Start with RetroDECK if you have none.

The emulators it drives

Five. RetroDECK and EmuDeck are front ends carrying a dozen emulators each, so a game goes to whichever one that system is configured for; RetroArch runs the libretro core RomMix names for the system; Eden and shadPS4 each run one console and nothing else. Settings → Platforms shows what every system resolves to, and lets you change it.

Getting it

Linux with flatpak, a RomM server at version 5 or newer that you can reach, and one of the emulators above — RomMix installs any of them but EmuDeck itself. Download the bundle from the releases page and install it for your user. 

flatpak remote-add --user --if-not-exists \
  flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./rommix-<version>-x86_64.flatpak

flatpak run be.bl_it.RomMix                  # desktop
gamescope -f -- flatpak run be.bl_it.RomMix  # on a TV

On a handheld, add that first command to Steam as a non-Steam game instead. There is no Flathub package yet, and the README covers building it yourself, the permissions it needs and what to do when an emulator will not start.
