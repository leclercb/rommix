RomMix

Your RomM library, on the television.

A Big Picture–style front end for your own RomM server. Browse like a console dashboard, download a game into your emulator's ROM folder, play it, and let the saves go back to RomM when you quit.

Open the demo Download Source on GitHub

The demo is the real interface, browsing the homebrew library from RomM's public demo: no server, no emulator, nothing installed. Arrow keys, Enter and Escape — or a controller, if one is plugged in.

What it does

RomM already holds the library. RomMix is the part that puts it on a screen you drive from the sofa, and gets the files where an emulator will find them.

Driven by a controller

Fullscreen, ten feet away: the whole app is navigable on a D-pad, under gamescope or added to Steam as a non-Steam game.

Downloads into the right folder

A game lands in its emulator's own library, so it is still there when you start that emulator yourself and ES-DE scrapes it as usual.

Saves that follow you

Newer saves come down before you play and go back up when you quit, with a per-game tab showing which side is ahead.

BIOS from your own server

Per platform: what is needed, what RomM holds and what the emulator already has — then the missing files are put in place.

Sign in from the couch

Show a code and a QR, approve it in RomM from a phone, and nothing secret is typed on a television keyboard.

Multi-disc, handled

A cue+bin or a multi-disc set is unpacked into a folder of its own, and the emulator is handed the .m3u, not the .bin.

The emulators it drives

Five, and RomMix installs the ones that can be installed. RetroDECK and EmuDeck are front ends carrying a dozen emulators each, so a game goes to whichever one that system is configured for; the other three run what they run.

Getting it

Linux with flatpak, a RomM server at version 5 or newer, and at least one of the emulators above. Download the bundle from the releases page and install it for your user. 

flatpak remote-add --user --if-not-exists \
  flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./rommix-<version>-x86_64.flatpak

flatpak run be.bl_it.RomMix                  # desktop
gamescope -f -- flatpak run be.bl_it.RomMix  # on a TV

There is no Flathub package yet, and the README covers building it yourself, the permissions it needs and what to do when an emulator will not start.
