# 01: `npm test` fails to start on Node 26

> _This was generated by AI during triage._

**Status:** needs-triage

**What happened:** `npm test` exits with `node: bad option: --experimental-transform-types` on Node 26, before any test runs. The husky pre-commit hook runs `npm test`, so every commit fails on such a machine.

**Established:**

- Seen on macOS after Homebrew upgraded `node` to 26.13.0 (2026-11-06). Node 26 no longer accepts the flag.
- `package.json` declares `"engines": { "node": ">=24" }`, so Node 26 is allowed by the project's own range.
- CI (`.github/workflows/*.yml`) pins `node-version: 24`, so CI is unaffected for now.
- Workaround used on 2026-11-07: put `/opt/homebrew/opt/node@24/bin` first on `PATH`; everything passes (1380/1383, 3 Linux-only skips).
- The flag appears in `test` and `test:coverage` in `package.json`.

**Open:** either make the test command work on both 24 and 26, or narrow `engines` and pin a local version (`.nvmrc`). The two are different decisions.
