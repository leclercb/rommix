# The Switch 2 is a system of its own, under a name ES-DE does not have

RomM catalogues the Switch 2 as its own platform (`switch-2`), and no Switch
emulator runs it: a Switch 2 game handed to one fails only once it is launched.
So it is a separate system, `switch2`, run only by emulators that declare it,
rather than one more slug on `switch`. ES-DE has no Switch 2 system to borrow a
name from, so `switch2` is RomMix's own, spelt the way ES-DE spells its systems.
It names the folder games are installed into on every machine, which is what
makes it costly to rename; if ES-DE ever adds the console under another name,
expect to adopt that one and to move what is already installed.

## Considered Options

- **`switch-2` as an extra slug on `switch`**: rejected. RomMix would offer
  Switch 2 games to Eden and the failure would surface at launch.
